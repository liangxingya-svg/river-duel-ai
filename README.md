# 河牌对决 · River Duel 0.0.16

网站入口：[https://riverduel.cn/](https://riverduel.cn/)。

网页德州扑克，虚拟筹码，无充值或提现。

- `index.html`：大厅入口，选择好友房、多人练习或经典单挑。
- `online.html`：2～12 人好友房，分享邀请链接加入，可添加 AI 补位。
- `online.html?practice=1`：本地多人练习，自动配齐 AI，可选筹码与盲注。
- `headsup.html`：经典单挑，三档 AI 难度和本机累计战绩。

0.0.5 重整手机竖屏牌桌与底部操作区，增加玩家头像、行动状态、阶段条、倒计时进度条、加注倍数与金额加减、专注模式和行动音效。修复同步时重置加注金额的问题。已完成的多人牌局按练习 / 好友分类保存在本机浏览器，最多 100 手，展示公共牌、本人底牌、净筹码与行动记录，新增按阶段、逐步与0.5x/1x/2x速度回放；旧记录仅提供结算摘要；清除浏览器数据会清除这些记录。

网页由 GitHub Pages 托管。当前好友房通过 `online-config.js` 配置的腾讯云 CloudBase WebSocket 后端通信。服务端统一洗牌、验证行动和处理主池 / 边池；邀请链接不包含座位凭证。新版默认决策 15 秒，可选 20 / 30 秒；离线等待 60 秒，超时可过牌时过牌，否则弃牌。连续三次超时暂停入局，准备后恢复。默认每手结算 5 秒后自动发下一手，也可选房主手动发牌。刷新使用本机座位凭证重新加入。

多人练习与好友房共用 `multiplayer.js` 规则引擎。AI 仅使用自己的底牌和公共信息，采用蒙特卡洛胜率估计及底池赔率启发式策略，并非专业 GTO 求解器。单机练习刷新后回到开房页面。

开发时使用静态 HTTP 服务打开网页。公共仓库保留原始 Workers 实现供参考，当前运行后端为腾讯云，网页无需 Cloudflare 账号。

验证：`node test.cjs`、`node multi-test.cjs`、`node ui-test.cjs`；覆盖牌型、下注顺序、短全押、边池、筹码守恒、底牌隔离、多人练习与本机记录。完整部署环境另有真实 HTTP / WebSocket 后端回归测试。

0.0.5 前后端更新：自定义2～12人；分阶段下注快捷项；金额为本轮总额，另显示本次投入；跟注预操作在金额改变后取消；主池/边池资格明细；逐步牌谱快照及未公开底牌隔离。好友房服务端按房间保存最近100手，凭原座位token重连同步；这不是微信登录或跨设备账号历史。需要同时发布新版腾讯后端，不能将前端升级视为后端已上线。

规则/联机自动回归通过，手机竖屏已完成响应式浏览器验收；不宣称与参考站所有功能完全一致。微信登录、实时语音频道、锦标赛、公开大厅发现和钱包未实现；房内短语音已实现。


## 0.0.9 牌桌工具

好友房支持房内文字聊天与最长10秒的短语音消息（先试听再发送，非实时语音频道）。文字保留最近50条，语音只推送给当前在线好友。补筹码为免费虚拟筹码，每次最多5,000，手中申请在结算后入账；本桌总结分别统计净输赢、补入及重开调整。每手结果可查看主池/边池分配及公开底牌，弃牌底牌继续保密。

## 0.0.11 声音与体验打磨

发牌、开牌、下注、全押、弃牌、行动提醒和结算使用各自的合成音效。设置中可试听，独立开关音效与背景音乐，选择原创“港片登场”或“深夜爵士”配乐、调整总音量；桌边可一键静音。首次进入牌桌后启用，音乐默认关闭；录语音时自动静音，播放好友语音时压低音乐，页面隐藏时暂停声音。所有配乐由程序原创合成，不使用电影《赌神》原声或录音。

每个房间按房间号生成一致的随机梗名，邀请链接与座位凭证逻辑不变。新消息显示未读标记；侧栏关闭按钮置于侧栏内，避免手机上的点击遮挡。结算清除下注筹码，未跟齐的普通下注不误显示为边池；练习房手中补筹码保留原倒计时，暂停入局后恢复状态同步到下一手。

新增验证：`node table-audio-test.cjs`、`node bet-layout-test.cjs`、`node practice-timing-test.cjs`、`node table-features-ui-test.cjs`。

## 0.0.12 稳定手机牌桌

手机牌桌采用独立牌桌舞台及固定高度操作区。等待、本人行动、等待对手、全押开牌、结算和重新开桌共用同一块舞台，底部内容变化只在操作区内排布或滚动。使用稳定视口单位，避免浏览器地址栏收起时牌桌跟着伸缩；横屏采用左右布局。

全押时展开对手已公开的底牌，结算后收成可展开摘要；详细结果保留在本手详情。弃牌、全押或旁观时有等待说明。座位卡固定高度，状态文字不改变座位位置。

`mobile-preview.html`提供320/360/390/430手机尺寸、横屏和六个阶段的布局验收。`layout-fixture.html`、`layout-fixture.js`是只读测试场景，不连接后端，不能当成真实好友房联机验收。


## 0.0.13 手机界面与牌桌互动

仅在手机尺寸应用新的比例：缩小牌面、大字号和面板，保留主要行动按钮的触摸区域；固定牌桌、本人手牌栏与公共牌锚点。六人桌公开底牌贴近座位，满员桌在固定座位卡内展示底牌。全押开牌按已公开底牌展示当前牌型和胜率（翻牌前为采样估计，不改变结算规则）。

手机聊天采用底部面板、本人/他人消息气泡、快捷表情与短语；自己的座位可打开快捷互动，发送后回到牌桌并短暂显示座位气泡。新消息不会重建已有语音节点或打断查看旧消息。语音仍为最长10秒的房内短消息；不是实时语音频道。

手机尺寸浏览器验收覆盖320×568、360×640、390×720、430×820，六人/十二人桌的等待、行动、对手行动、全押、结算及重开阶段；这不是物理手机或微信浏览器验收。


## 0.0.16 标准三人斗地主

`doudizhu.html` 是独立的斗地主大厅；`doudizhu.html?practice=1` 可进入本机AI练习。好友房固定3人，可以邀请朋友或补入AI。德州入口和既有房间继续保留。

54张牌、17/17/17手牌与3张地主底牌；纯随机安全洗牌；叫抢地主、加倍、明牌、全部常见牌型、炸弹/王炸、春天/反春天，详细边界见页面规则。服务端持有未公开手牌并验证每次行动，AI只读取自己的手牌和公开信息。

手机支持点击/滑动连选、提示轮换、取消选择、固定舞台与操作区；房内文字/短语音、排行榜、补筹码、收益与自动补齐次数、完整出牌时间线和刷新恢复。练习最近40局记录在本机；好友房最近100局保存在服务器。普通出牌30秒，连续3次超时暂停下一局，准备后恢复；结算展示8秒再发牌。

净输赢按地主与两名农民分别结算，筹码上限内按比例分配，收益总和为0；补入与补齐不算收益。管理页识别斗地主房间、牌局阶段和对应邀请链接，继续执行连续无人24小时解散。

验证：`node doudizhu-test.cjs`（250局AI、牌型/叫抢/隐私/结算/补齐边界），完整后台另有真实三客户端HTTP/WebSocket联机、非法出牌/重复请求/保存恢复、管理与德州兼容性回归。
