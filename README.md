# 河牌对决 · River Duel 0.0.1

单机无限注德州扑克，玩家与 AI 一对一，双方初始 2000 虚拟筹码，盲注 10/20。无充值或提现。

界面借鉴 River Club 可见首页的墨绿配色、扑克牌、筹码与俱乐部氛围，自行实现完整牌桌交互。快捷下注、全押、庄家标识、牌局记录、摊牌高亮、三档 AI、本地战绩、手机布局。

AI：蒙特卡洛抽样估算胜率，结合底池赔率、简化对手范围与随机诈唬。仅接收自己的手牌、公共牌及公开下注信息。不是 CFR 或 GTO 求解器。

浏览器打开 index.html 即可；推荐通过静态 HTTP 服务器运行以启用 Web Worker。无第三方运行依赖。浏览器保存已结算的筹码与累计战绩，未完成的手牌刷新后回到最近结算状态。

验证：`node test.cjs` 检查牌型、行动顺序、合法加注、400 次随机对局筹码守恒与 AI 输入隔离。
