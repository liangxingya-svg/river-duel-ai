# 河牌对决 · River Duel 0.0.5

网页德州扑克，虚拟筹码，无充值或提现。

- `index.html`：大厅入口，选择好友房、多人练习或经典单挑。
- `online.html`：2～12 人好友房，分享邀请链接加入，可添加 AI 补位。
- `online.html?practice=1`：本地多人练习，自动配齐 AI，可选筹码与盲注。
- `headsup.html`：经典单挑，三档 AI 难度和本机累计战绩。

0.0.5 重整手机竖屏牌桌与底部操作区，增加玩家头像、行动状态、阶段条、倒计时进度条、加注倍数与金额加减、专注模式和行动音效。修复同步时重置加注金额的问题。已完成的多人牌局按练习 / 好友分类保存在本机浏览器，最多 100 手，展示公共牌、本人底牌、净筹码与行动记录，新增按阶段、逐步与0.5x/1x/2x速度回放；旧记录仅提供结算摘要；清除浏览器数据会清除这些记录。

网页由 GitHub Pages 托管。当前好友房通过 `online-config.js` 配置的腾讯云 CloudBase WebSocket 后端通信。服务端统一洗牌、验证行动和处理主池 / 边池；邀请链接不包含座位凭证。新版默认决策 15 秒，可选 20 / 30 秒；离线等待 60 秒，超时可过牌时过牌，否则弃牌。连续三次超时暂停入局，准备后恢复。默认每手结算 5 秒后自动发下一手，也可选房主手动发牌。刷新使用本机座位凭证重新加入。

多人练习与好友房共用 `multiplayer.js` 规则引擎。AI 仅使用自己的底牌和公共信息，采用蒙特卡洛胜率估计及底池赔率启发式策略，并非专业 GTO 求解器。单机练习刷新后回到开房页面。

开发时使用静态 HTTP 服务打开网页。公共仓库保留原始 Workers 实现供参考，当前运行后端为腾讯云，网页无需 Cloudflare 账号。

验证：`node test.cjs`、`node multi-test.cjs`、`node ui-test.cjs`；覆盖牌型、下注顺序、短全押、边池、筹码守恒、底牌隔离、多人练习与本机记录。完整部署环境另有真实 HTTP / WebSocket 后端回归测试。

0.0.5 前后端更新：自定义2～12人；分阶段下注快捷项；金额为本轮总额，另显示本次投入；跟注预操作在金额改变后取消；主池/边池资格明细；逐步牌谱快照及未公开底牌隔离。好友房服务端按房间保存最近100手，凭原座位token重连同步；这不是微信登录或跨设备账号历史。需要同时发布新版腾讯后端，不能将前端升级视为后端已上线。

实际规则/联机回归通过，手机与桌面新版视觉验收尚待完成；不宣称与参考站所有功能完全一致。微信登录、语音、锦标赛、公开大厅发现和钱包未实现。


## 0.0.9 牌桌工具

好友房支持房内文字聊天与最长10秒的短语音消息（先试听再发送，非实时语音频道）。文字保留最近50条，语音只推送给当前在线好友。补筹码为免费虚拟筹码，每次最多5,000，手中申请在结算后入账；本桌总结分别统计净输赢、补入及重开调整。每手结果可查看主池/边池分配及公开底牌，弃牌底牌继续保密。
